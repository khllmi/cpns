# Pejuang ASN — Latihan SKD CPNS 2026

Aplikasi latihan SKD CPNS (TWK, TIU, TKP, SKB) sesuai kisi-kisi SKD 2026 dari JDIH KemenPANRB.

- Latihan Bebas (pilih banyak bab) dan Drilling Adaptif (Mudah → Sedang → Sulit → HOTS)
- Tryout bergaya CAT: 110 soal / 100 menit, tanda ragu-ragu, pembahasan
- Rangkuman materi dan kisi-kisi 2026
